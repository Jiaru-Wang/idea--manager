# IdeaMiner 论文雷达与 Paper Lab 使用说明

## 这次增加了什么

IdeaMiner 现在可以完成一条完整的论文学习流程：

1. 在“论文雷达”输入研究兴趣、目标期刊或会议、起始年份。
2. 后端同时检索 OpenAlex 与 Crossref 的公开论文元数据。
3. 系统按 DOI 或标题去重，并合并作者、摘要、期刊、年份、引用量和开放获取信息。
4. 点击“填入”可把候选论文放入 Paper Lab；点击“直接分析”会填入论文并立即运行全链路分析。
5. 分析结果可保存成 IdeaMiner 中的 Idea，继续建立关系、复现计划和新研究方向。

“每次打开自动更新”只会在本机打开 Paper Lab 时运行一次检索，不是云端定时通知。研究兴趣和筛选条件保存在浏览器本地存储中。

## 使用步骤

### 1. 配置模型

打开顶部的 `Agent`，选择 `MiniMax`，填写中国区 API Key，确认模型和接口地址后保存。密钥保存在操作系统安全存储或当前进程会话中，不进入 SQLite、浏览器本地存储、导出文件或 Git 仓库。

### 2. 搜索论文

打开顶部的 `Paper Lab`：

- “你想跟进的研究主题”：填写关键词，例如 `EEG emotion recognition cross-subject generalization`。
- “目标期刊或会议”：可留空，也可用逗号填写多个精确名称，例如 `TPAMI, TNNLS, NeurIPS`。
- “起始年份”：限制近期论文。
- “每次打开自动更新”：记住条件，并在下次打开 Paper Lab 时自动刷新候选列表。

这里不会使用固定的“顶刊榜单”。顶刊标准依赖学科和论文类型，由用户填写目标渠道，避免把医学、AI、工程、理论和社会科学套进同一套评价标准。

### 3. 直接分析

每篇候选论文提供两个操作：

- `填入`：只填写题目、DOI、期刊、研究领域和摘要，允许继续修改。
- `直接分析`：填写论文后立即运行“全链路”分析并输出结果。

MiniMax 预设本身不提供服务端网页搜索。论文雷达先用 OpenAlex/Crossref 提供可核验的论文元数据和摘要；作者近年轨迹、全文实验细节等无法由输入确认的内容仍会标记为“待核验”，不会编造。

## Paper Lab 的分析模块

- `全链路`：证据边界、题目、作者轨迹、Introduction、论证链、交叉知识、复现和新 Idea。
- `题目与作者`：分析“表型 + 机制”的题目结构和实验室研究积累。
- `综述逻辑`：重建“已知 -> 未知 -> 矛盾/窗口 -> 科学猜想”。
- `因果实验链`：检查干预、对照、救援、反证、替代解释和场景迁移。
- `交叉知识桥`：把难点抽象为功能或数学问题，再跨领域寻找机制、模型和工具。
- `代码复现`：建立 Figure/Table 到数据、代码、配置、命令、输出和验收指标的映射。
- `新 Idea`：从证据缺口和跨学科迁移中形成可证伪的新方向。

不同论文会先识别期刊、论文类型和研究设计，再选择对应的证明责任，不会把生物医学救援实验机械套到 AI、理论或工程论文上。

## 数据流与安全边界

```text
研究兴趣与期刊条件
        |
        v
IdeaMiner 后端 ----> OpenAlex / Crossref 公共元数据 API
        |
        v
候选论文去重、合并、排序
        |
        v
用户选择论文 ----> Paper Lab 提示词 ----> 已配置的大模型
        |
        v
分析报告 ----> 用户确认后保存为 Idea
```

- 真实 API Key 不得写入 `.env.example`、源码、测试或文档。
- `.env`、数据库、个人资料、构建目录和虚拟环境均已由 `.gitignore` 排除。
- `OPENALEX_API_KEY` 是可选项，只用于提高 OpenAlex API 配额；不填写也可检索。
- 外部请求有 12 秒超时和 2 MB 响应上限；任一元数据来源失败时会使用另一来源并显示提示。

## 主要代码位置

- `backend/app/main.py`：MiniMax 适配、学术元数据检索、合并与排序。
- `backend/app/schemas.py`：Agent provider 类型。
- `backend/tests/test_api.py`：MiniMax 与论文检索行为测试。
- `src/components/AgentWorkspace.tsx`：MiniMax 配置界面。
- `src/components/PaperWorkspace.tsx`：论文雷达、分析模块、直接分析和报告保存。
- `src/components/PaperWorkspace.css`：桌面与移动端布局。
- `src/api.ts`、`src/types.ts`：前后端请求和 TypeScript 数据契约。

## 本机启动

在仓库根目录执行：

```bash
.venv/bin/python launcher.py
```

正常情况下打开：

- 网站：`http://127.0.0.1:5173`
- API 文档：`http://127.0.0.1:8000/docs`

这是本机地址。电脑关机或 IdeaMiner 退出后，需要重新运行启动命令。
